# Java and Kotlin training

Here a training course is created to teach Java and Kotlin to an experienced software developer who happens to have no prior experience with those technologies but mainly with the full .NET stack and Javascript/Typescript web frontend technologies.

As an example project a mobile app for an advanced version of Tic-Tac-Toe called Fritz. The app is developed in Kotlon and runs on Android. For the multiplayer experience a backend developed in modern Java is providing account management and communication between the players.
